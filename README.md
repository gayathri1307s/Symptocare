# SymptoCare 🩺
### AI-Based Symptom Analysis for Health Risk Prediction

SymptoCare is an AI-powered healthcare project designed to analyze user-provided symptoms and health information to predict potential health risks. It combines machine learning and natural language processing to support preliminary health risk assessment.

## ✨ Features

- **Symptom Analysis:** Processes user-provided symptoms.
- **Health Risk Prediction:** Uses machine learning models to predict potential risks related to Type 2 Diabetes and Chronic Kidney Disease (CKD).
- **AI Chatbot:** Provides a conversational interface for symptom-related interaction.
- **Mobile Application:** Flutter-based frontend for user interaction.

## 🛠️ Tech Stack

- **Frontend:** Flutter, Dart
- **Backend:** Python
- **Machine Learning:** K-Nearest Neighbors (KNN), model-based prediction
- **AI/NLP:** Natural Language Processing
- **Tools:** Jupyter Notebook, Firebase

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/gayathri1307s/Symptocare.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Symptocare
   ```

3. Explore the `backend/`, `frontend/`, and `ml/` directories to understand the individual components.

4. Install the dependencies required for each component using its respective dependency files.

## ⚠️ Disclaimer

SymptoCare is an educational project intended for preliminary health risk assessment. Its predictions are not medical diagnoses and should not replace professional medical advice.
